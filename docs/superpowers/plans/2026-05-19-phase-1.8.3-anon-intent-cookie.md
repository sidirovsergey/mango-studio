## Sub-phase A — Cookie helper

**File:** `apps/web/src/lib/auth/pending-intent-cookie.ts` (NEW)

### Tasks
- A1. Constants: `PENDING_INTENT_COOKIE = 'mango_pending_intent'`, `TTL_MS = 30 * 60_000`, `MIN_SECRET_BYTES = 32`.
- A2. `getPendingIntentSecret(): Buffer` — read `process.env.PENDING_INTENT_SECRET`. Explicit format selection (Codex Sub-phase A SHIP-WITH-FIXES, 2026-05-20): if value starts with `base64:` → decode the suffix as base64; otherwise use raw utf-8 bytes. Throw `Error('PENDING_INTENT_SECRET not set')` on missing; throw `Error('PENDING_INTENT_SECRET too short (<32 bytes)')` on weak.
- A3. `encodePendingIntent(payload): string` — payload includes `exp = now + TTL_MS`. `payload_b64 = base64url(JSON.stringify(payload))`. `hmac_b64 = base64url(HMAC-SHA256(payload_b64, secret))`. Return `payload_b64 + '.' + hmac_b64`.
- A4. `decodePendingIntent(token): PendingIntentPayload | null` — split on `.` (require exactly 2 segments, both non-empty). Recompute HMAC over `payload_b64`. Decode supplied HMAC → Buffer. Check `recomputed.length === supplied.length`; if not → null. `timingSafeEqual` → if mismatch → null. JSON.parse `payload_b64` → wrap in try/catch → null on throw. Validate via Zod schema:
  ```ts
  const PendingIntentSchema = z.object({
    kind: z.enum(['render', 'studio']),
    project_id: z.string().uuid(),
    return_to: z.string().min(1).max(256).refine(/* mirror TopupInputSchema.intent.return_to predicates */),
    exp: z.number().int().positive(),
  });
  ```
  → null on parse fail. Check `exp > Date.now()` → null on expiry.
- A5. `setPendingIntent(payload: Omit<PendingIntentPayload, 'exp'>): Promise<void>` — encode, write cookie via `next/headers.cookies().set(name, value, {httpOnly: true, secure: true, sameSite: 'lax', path: '/', maxAge: TTL_MS / 1000})`.
- A6. `consumePendingIntent(): Promise<PendingIntentPayload | null>` — read cookie. If absent → null + no delete. If present → call delete-cookie helper (`cookies().set({name, value: '', maxAge: 0, path: '/'})`) **regardless** of decode result (clear-on-read for invalid cookies too, Codex SHOULD-FIX #4). Then decode + return result.
