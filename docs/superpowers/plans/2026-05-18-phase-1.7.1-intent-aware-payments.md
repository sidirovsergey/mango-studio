# Phase 1.7.1 — Intent-aware Payments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Tasks use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend v1.7.0 top-ups with an intent ledger (`billing_intents` table) so post-payment redirect resumes render/studio entries idempotently. Webhook auto-enqueues render on payment success (Codex UX reversal). Extends pricing surface for future CJM §6.3 granular pricing without breaking v1.7.0.

**Spec:** [`docs/superpowers/specs/2026-05-18-phase-1.7.1-intent-aware-payments-design.md`](../specs/2026-05-18-phase-1.7.1-intent-aware-payments-design.md)

**Pre-requisite:** v1.7.0 merged to main. `NEXT_PUBLIC_PAYMENTS_UI_ENABLED=false` + `PAYMENTS_GATE_ENFORCE=false` in prod when 1.7.1 ships (1.7.1 keeps flags state, no flip).
