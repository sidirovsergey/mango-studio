# SYNTX.ai — Investment & Technical Due Diligence

**Заказчик:** команда Mango Studio (mangopro.ru)
**Цель:** оценить продукт SYNTX (https://syntx.ai) как ориентир для запуска собственного мульти-модельного AI-генератора (чат/фото/видео/аудио) для рынка Индонезии, включая Telegram-first дистрибуцию.
**Дата:** 2026-07-11
**Методология:** открытые источники (сайт продукта, публичные страницы, поисковая выдача, ценовые страницы провайдеров API/GPU, публичная статистика рынка). Ничего не выдумано — там, где данные не найдены, стоит пометка «НЕ НАЙДЕНО» и, где возможно, оценка по косвенным признакам с объяснением логики.

## Как читать пометки достоверности

- **[FACT]** — подтверждено первичным источником, ссылка приведена.
- **[EST]** — расчёт/оценка на основе косвенных данных; формула и допущения раскрыты.
- **[UNKNOWN]** — данных недостаточно, ни расчёт, ни наблюдение не дают надёжной оценки; указан диапазон "best guess" при возможности, либо явно "неизвестно".

## Ограничения исследования

SYNTX не публикует исходный код, внутреннюю документацию или контракты с провайдерами. Все архитектурные выводы в разделе 1 — это **реконструкция по внешним признакам** (публичный UX, тарифная страница, паттерны индустрии), а не подтверждённый факт устройства их бэкенда. Это явно помечено везде, где применимо.
