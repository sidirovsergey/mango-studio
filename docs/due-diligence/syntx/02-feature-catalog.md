## 2.6 Функции, которых нет у SYNTX (окно возможностей — детали в Этапе 10)

- Официальная поддержка индонезийских способов оплаты (QRIS/GoPay/OVO/DANA/ShopeePay).
- Локализация интерфейса на Bahasa Indonesia.
- Прозрачная, единая (не противоречащая по источникам) тарифная сетка — у SYNTX цены расходятся между сторонними обзорами, что указывает на непрозрачность/нестабильность прайсинга.
- Публичный статус генерации в реальном времени с честной оценкой времени ожидания (у SYNTX — жалобы на "несколько часов без обратной связи").
- Официальный API для сторонних интеграций (SYNTX явно этого не предлагает — ниша для B2B/партнёрской модели).
