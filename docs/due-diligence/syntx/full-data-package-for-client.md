# Полный пакет данных аудита SYNTX — для заказчика

Все таблицы и цифры, использованные при технико-экономической оценке проекта. Каждая цифра — со ссылкой на первичный источник или с пометкой метода расчёта. Развёрнутое обоснование по каждому разделу — в соответствующем файле пакета (`01-...md` – `10-...md`, `07-financial-model.md`, `08-roadmap.md`, `risk-assessment.md`).

**Как читать пометки достоверности:**
- **[FACT]** — подтверждено первичным источником (сайт, документ, live pricing-страница).
- **[EST]** — расчёт/оценка на основе косвенных данных, формула и допущения раскрыты.
- **[UNKNOWN]** — данных недостаточно; указан диапазон или явно "неизвестно".
